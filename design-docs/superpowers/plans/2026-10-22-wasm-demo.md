### Task 2: Embind binder + build script

**Files:**
- Create: `web/planner_bind.cpp`

**Interfaces:**
- Produces JS: `Module.plan(mapJson: string, algorithm: string, informed: boolean) -> string` (JSON result)

Binder sketch:

```cpp
#include <emscripten/bind.h>
#include "uav/astar3d.hpp"
#include "uav/rrt_star.hpp"
#include <sstream>
std::string plan(std::string map_json, std::string algo, bool informed) {
  auto cfg = uav::load_map_json_string(map_json);
  uav::Environment env(cfg);
  uav::PlannerStats st;
  if (algo == "rrtstar") {
    uav::RRTStar3D rrt(env, /*seed*/42, informed);
    st = rrt.plan(cfg.start, cfg.goal);
  } else {
    uav::AStar3D astar(env);
    st = astar.plan(cfg.start, cfg.goal);
  }
  // serialize success, metrics, path to JSON string
  return json;
}
EMSCRIPTEN_BINDINGS(uav) { emscripten::function("plan", &plan); }
```
